01 / PROFILE

关于我

我从具体的使用问题出发做软件：让桌面操作更顺手，让 Android 分区工具更容易构建，让跨平台应用从源码到发布包的过程更可检查。我关注功能实现，也在意依赖、构建、验证、签名和发布之间的边界是否清楚。

这些项目覆盖 Rust、C/C++、C#、Python 和 Shell，也涉及 Win32、Linux 桌面接口、Android 构建系统与 GitHub Actions。

系统与桌面工具Windows、Linux 与 Raspberry Pi 上的小型原生工具。
Android 平台动态分区命令行工具、依赖构建与多架构分发。
构建与发布自动化构建、制品校验、资格检查和受控发布流程。

02ANDROID / TOOLCHAIN

Android LP Tools

github.com/billradar/android-lp-tools ↗

Android 动态分区工具的独立构建与分发套件。

统一构建 lpmake、lpadd、lpflash、lpunpack 和 lpdump，自动准备静态依赖，并提供 x86_64 与 ARM64 构建流程，无需完整 Android SDK/NDK 环境。

一键关闭显示器，同时保持电脑运行和会话解锁。

Desktop Layout Manager

github.com/billradar/DesktopLayoutManager ↗

查看、保存和恢复 Windows 桌面图标布局。
