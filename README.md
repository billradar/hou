# Radar — 个人主页与项目集

> **[访问个人主页 →](https://billradar.github.io/hou/)**
>
> 这里集中介绍我实际开发和维护的项目，涵盖桌面与设备工具、Android 平台工具，以及软件构建和发布工程。

## 项目

| 项目 | 简介 | 地址 |
| --- | --- | --- |
| **[RustDesk Custom](https://github.com/billradar/rustdesk-custom)** | 维护 RustDesk 定制补丁，并建设跨平台构建、制品校验和发布流程。 | [GitHub](https://github.com/billradar/rustdesk-custom) |
| **[Android LP Tools](https://github.com/billradar/android-lp-tools)** | 独立构建 Android 动态分区工具，提供 x86_64 与 ARM64 构建和发布包。 | [GitHub](https://github.com/billradar/android-lp-tools) |
| **[MonitorOff](https://github.com/billradar/MonitorOff)** | 一键关闭显示器的 Windows/Linux 工具；支持 X11、Sway 和 Hyprland。 | [GitHub](https://github.com/billradar/MonitorOff) |
| **[Desktop Layout Manager](https://github.com/billradar/DesktopLayoutManager)** | 使用 Rust 和 Win32 管理 Windows 桌面图标布局，支持保存、恢复和整理。 | [GitHub](https://github.com/billradar/DesktopLayoutManager) |
| **[rpi-led](https://github.com/billradar/rpi-led)** | Raspberry Pi LED 定时控制服务，附安装脚本并支持多种启动方式。 | [GitHub](https://github.com/billradar/rpi-led) |

每个项目的功能范围、技术栈和发布状态见[个人主页](https://billradar.github.io/hou/#projects)。
